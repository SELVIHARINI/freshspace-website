
# FreshSpace Cleaning Services Website

## Project Overview
FreshSpace is a responsive sample website for a local cleaning service business. It helps customers explore cleaning services, compare sample prices, read FAQs, and request a quote.

## Features
- Responsive homepage design
- Navigation menu for desktop and mobile
- Cleaning service descriptions
- Sample pricing plans
- About section
- Interactive FAQ accordion
- Quote request form with validation
- Footer with contact information
- Responsive layout for mobile, tablet, and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
freshspace-website/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure all three source files are in the same folder.
4. Open `index.html` in your browser.
5. An internet connection is needed to display the external images.

## Website Sections
- Home
- Services
- Pricing
- About
- Frequently Asked Questions
- Contact and Quote Request Form

## Important Notes
- This is a demonstration website.
- Pricing and contact information are examples and should be customized.
- The quote form validates user input but does not send data to a server.
- External images require an internet connection.
